# 统一记账系统（Unified Ledger）UI/UX 设计规范

> 文档版本：v1.0
> 创建日期：2026-06-06
> 适用技术栈：Vue 3 + Element Plus + Pinia + Vue Router + ECharts
> 配套文档：`unified-ledger-design.md`（领域模型与开发规划）
> 性质：前端工程师可直接照此实现的落地级 UI/UX 规范

---

## 0. 阅读指引

- 本规范与 `unified-ledger-design.md` 的数据模型严格对齐（账本 Ledger / 类目 Category / 商品 Product / 账目 Transaction / 来源平台 SourcePlatform）。
- 金额一律「整数分」存储，所有展示组件在「展示层」做分/元转换（统一 `utils/money.ts`），UI 层禁止用 float 参与业务计算。
- 组件命名、属性、令牌均落到具体值，无歧义。Element Plus 版本以 `2.5+` 为基准。
- 全文「主色 / 收入绿 / 支出红」语义统一，禁止在页面里临时换色。

---

## 1. 设计风格定位

### 1.1 总体定位

| 维度 | 定位 | 说明 |
| --- | --- | --- |
| 调性 | 清爽 · 高效 · 财务可信赖 | 记账是高频低耐心场景，去装饰、重信息密度与录入速度 |
| 信息密度 | 中高（PC 优先） | 列表/表单为主，单屏尽量给足信息，减少滚动与跳转 |
| 视觉重心 | 金额与收支方向 | 金额是第一信息，红绿语义贯穿全局 |
| 交互哲学 | 「默认值优先 + 减少点击」 | 快捷记账目标 10 秒一笔，能预填的绝不让用户填 |
| 风格参考 | Element Plus 默认体系 + 轻拟物卡片 | 不引入第三方设计语言，保持组件库一致性，降低自研成本（DRY） |

### 1.2 设计原则

1. **金额至上**：任何场景金额都用等宽数字、千分位、红绿语义，且字号大于周边文本。
2. **账本上下文恒可见**：顶栏账本切换器常驻，用户任何时候都知道「我在哪个账本」。
3. **按账本类型收敛界面**：个人账本隐藏商品/利润相关入口，避免认知负担。
4. **录入路径最短**：快捷记账走「类目→金额→保存」三步，支持连录不打断。
5. **空状态即引导**：每个列表/页面的空状态都给出明确的「下一步」按钮。

## 3. 字体与字号层级

### 3.1 字体族

```scss
--font-family-base: "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
/* 金额、数字专用等宽，保证对齐与可读 */
--font-family-number: "DIN Alternate", "Roboto Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace;
```

> 金额、统计数字、表格金额列统一使用 `--font-family-number`，并启用 `font-variant-numeric: tabular-nums;` 保证千分位与小数点纵向对齐。

### 3.2 字号层级（type scale）

| 级别 | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| 数字-超大 Display | 32px | 40px | 600 | 仪表盘三大卡片金额 |
| 数字-大 | 24px | 32px | 600 | 快捷记账金额显示、利润核算汇总 |
| 标题 H1 | 20px | 28px | 600 | 页面主标题 |
| 标题 H2 | 16px | 24px | 600 | 卡片标题、分组标题 |
| 正文-大 | 15px | 24px | 400 | 表单 label、重要正文 |
| 正文 Body | 14px | 22px | 400 | 默认正文、表格内容（EP 默认） |
| 辅助 Caption | 13px | 20px | 400 | 时间戳、备注、表单提示 |
| 标注 Mini | 12px | 18px | 400 | Tag 文本、角标 |

### 3.3 金额展示字重规则

- 金额数值：字重 `600`，等宽字体。
- 金额前缀符号（`+` / `-` / `¥`）：与数值同色，字号小一档。
- 收入金额前缀 `+`、支出金额前缀 `−`（U+2212 真减号，非连字符，视觉更整齐）。

## 4. 间距与栅格规范（8px 基准）

### 4.1 间距令牌

基准 8px，提供 4px 半档用于紧凑场景：

| 令牌 | 值 | 典型用途 |
| --- | --- | --- |
| `--space-1` | 4px | 图标与文字间距、Tag 内边距 |
| `--space-2` | 8px | 表单项内元素间距、紧凑列表行内距 |
| `--space-3` | 12px | 卡片内文本块间距 |
| `--space-4` | 16px | 卡片内边距、表单项纵向间距 |
| `--space-5` | 24px | 卡片之间间距、区块间距 |
| `--space-6` | 32px | 页面区块大间距 |
| `--space-7` | 48px | 空状态上下留白 |

### 4.2 布局栅格

- 内容区主体使用 Element Plus `el-row` / `el-col`，24 栅格，列间距（gutter）= `16`。
- 仪表盘卡片：每张占 `span=8`（PC 三等分），中屏 `md` 降为 `span=12`，小屏 `xs` 为 `span=24`。
- 页面内容最大宽度建议 `1440px` 居中（超宽屏两侧留白），最小适配宽度 `1024px`。

### 4.3 圆角与阴影

| 元素 | 圆角 | 阴影 |
| --- | --- | --- |
| 卡片 Card | 8px | `0 1px 2px rgba(0,0,0,0.04), 0 2px 8px rgba(0,0,0,0.04)` |
| 按钮/输入 | 6px | 无（聚焦时主色 2px 描边） |
| 弹窗 Dialog | 12px | EP 默认 |
| Tag | 4px | 无 |
| 快捷类目按钮 | 10px | hover 时 `0 2px 8px rgba(59,110,246,0.15)` |

## 5. 关键通用组件规范

> 这些是跨页面复用的核心组件，建议落到 `src/components/`，是 DRY 的关键。

### 5.1 金额展示组件 `<AmountText>`

**职责**：统一所有金额的显示（千分位、红绿语义、符号、单位）。

**Props**

| prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `cents` | number | — | 金额（整数分），唯一数据来源 |
| `flow` | `'income' \| 'expense' \| 'neutral'` | `'neutral'` | 决定颜色与符号 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 14 / 16 / 24 / 32 px |
| `showSign` | boolean | `true` | 是否显示 `+`/`−` |
| `showSymbol` | boolean | `true` | 是否显示 `¥` |
| `colored` | boolean | `true` | 是否上色（表格里有时只需纯黑） |

**渲染规则**

- 内部调用 `money.format(cents)` → 元（保留 2 位小数）+ 千分位，如 `1234567` 分 → `12,345.67`。
- `flow=income` → 绿色 `#1FA971`，前缀 `+`。
- `flow=expense` → 红色 `#E04C4C`，前缀 `−`。
- `flow=neutral` → 文本主色 `#1F2329`，无方向符号（用于结余/总额，正负另由数值判断可选上色）。
- 结余特例：传 `flow=neutral`，组件内若 `cents>0` 显绿、`cents<0` 显红、`=0` 显中性灰（通过 `balanceColored` 内部逻辑或外层判断后传 flow）。
- 使用等宽字体 + `tabular-nums`。

**示例呈现**

```
收入：+¥12,345.67   (绿)
支出：−¥   89.00    (红)
结余： ¥ 3,210.00   (绿/红/灰，无方向符)
```

### 5.2 金额输入组件 `<AmountInput>`

**职责**：以「元」录入，对外吐「分」，零浮点误差。

**Props / Emits**

| 项 | 说明 |
| --- | --- |
| `v-model` | 绑定值为「整数分」(number)；内部显示为元 |
| `flow` | `income/expense`，决定输入框左侧前缀色与符号 |
| `autofocus` | 录入页默认聚焦 |
| `size` | EP size，快捷记账用 `large` |

**实现要点**

- 基于 `el-input`（非 `el-input-number`，因需精确控制小数与千分位、避免 step 干扰）。
- 输入限制：正则 `^\d{0,9}(\.\d{0,2})?$`，最多 2 位小数、最大 9 位整数。
- 失焦时格式化为千分位显示；聚焦时切回纯数字便于编辑。
- 转换走 `money.toCents(yuan)`（用字符串解析 + 四舍五入到分，禁止 `yuan*100` 浮点）：
  ```ts
  // money.ts
  export const toCents = (yuan: string | number): number =>
    Math.round(Number(yuan) * 100); // 入口已限制 2 位小数，Math.round 兜底
  export const fromCents = (cents: number): string => (cents / 100).toFixed(2);
  export const format = (cents: number): string =>
    fromCents(cents).replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  ```
- 前缀 slot：左侧固定 `¥`，颜色随 `flow`。
- 大号场景（快捷记账）：字号 28px、高度 56px、右对齐数字。

```
┌──────────────────────────────┐
│ ¥            1,280.00      ⌫ │   ← 右对齐, 等宽, flow 决定 ¥ 颜色
└──────────────────────────────┘
```

### 5.3 类目选择器 `<CategoryPicker>`

**职责**：在「当前账本 + 当前收支方向」下选择类目，支持父子两级。

**Props**

| prop | 说明 |
| --- | --- |
| `v-model` | `category_id` |
| `flow` | `income/expense`，只列出对应 flow_type 的类目 |
| `mode` | `'cascader'`（表单用，级联选择）\| `'grid'`（快捷记账用，常用类目按钮宫格） |

**两种形态**

1. **级联模式 `cascader`**（账目录入表单 / 列表筛选）
   - 基于 `el-cascader`，`props.checkStrictly=true`（允许只选父级），`emitPath=false`（只吐叶子/选中节点 id）。
   - 数据按 `parent_id` 构树；空类目时显示「该账本暂无收入/支出类目，去新建」链接（跳类目管理）。
2. **宫格模式 `grid`**（快捷记账）
   - 展示当前 flow 下「常用类目」（取使用频次 Top N，前端可按最近 30 天交易聚合，或后端给 `usage_count`）。
   - 每个类目一个圆角按钮（图标 + 名称），选中态主色描边 + 浅底。
   - 末位固定一个「更多 ⋯」按钮，点开弹出全量类目选择（cascader 或抽屉）。

```
grid 模式（支出）:
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ 🍚   │ │ 🚕   │ │ 🛒   │ │ 🏠   │
│ 餐饮 │ │ 交通 │ │ 购物 │ │ 居家 │
└──────┘ └──────┘ └──────┘ └──────┘
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ 💊   │ │ 🎮   │ │ 📚   │ │ ⋯    │
│ 医疗 │ │ 娱乐 │ │ 学习 │ │ 更多 │
└──────┘ └──────┘ └──────┘ └──────┘
```

### 5.4 账本切换器 `<LedgerSwitcher>`（顶栏核心）

**职责**：切换全局账本上下文，是全系统数据隔离的入口控件。

**实现**

- 顶栏左侧，`el-dropdown`，触发区显示「当前账本名 + 类型徽标 + ▾」。
- 类型徽标：个人账本 → 蓝色 Tag「个人」；生意账本 → 橙色 Tag「生意」。
- 下拉项：列出所有账本（分「个人」「生意」两组），当前项打勾；底部固定「＋ 新建账本」「⚙ 管理账本」。
- **切换副作用（关键）**：
  1. 写入 Pinia `useLedgerStore().currentLedger`，并持久化到 `localStorage`。
  2. 触发全局数据失效：清空/重拉类目、商品、账目筛选项缓存。
  3. **按类型重建侧边菜单**：`type=business` 显示「商品管理 / 利润核算」，`type=personal` 隐藏（见 6.1）。
  4. 当前若在生意专属页（如利润核算）而切到个人账本 → 自动重定向到仪表盘，避免空白页。
- 切换有轻微过渡（内容区 200ms 淡入），并 Message 提示「已切换到『XX 账本』」。

```
┌─────────────────────────────────┐
│  📒 我的生活  [个人] ▾           │  ← 顶栏触发区
└─────────────────────────────────┘
        ▼ 展开
   ┌──────────────────────────┐
   │ 个人                     │
   │   ✓ 我的生活   [个人]    │
   │     家庭账    [个人]     │
   │ 生意                     │
   │     微商小店  [生意]     │
   │     批发档口  [生意]     │
   │ ───────────────────────  │
   │ ＋ 新建账本              │
   │ ⚙ 管理账本              │
   └──────────────────────────┘
```

### 5.5 收支方向切换 `<FlowToggle>`

- 用于快捷记账与录入表单顶部，二选一分段控件。
- 基于 `el-radio-group` + `el-radio-button`（或 `el-segmented`，EP 2.5+）。
- 「支出」在左（默认选中，因日常支出更高频）、「收入」在右。
- 选中「支出」→ 控件主色变红；选中「收入」→ 变绿。整页主色调随之联动（金额前缀、保存按钮颜色）。

```
┌───────────┬───────────┐
│  ● 支出   │   收入     │   ← 选中支出: 红底白字; 选中收入: 绿底白字
└───────────┴───────────┘
```

### 5.6 空状态 `<EmptyState>`

- 基于 `el-empty`，统一插画/图标 + 一句说明 + 一个主行动按钮。
- 文案模板：
  - 账目列表空：「当前筛选条件下还没有账目」+ 按钮「去记一笔」。
  - 类目空：「还没有{收入/支出}类目」+ 按钮「新建类目」。
  - 商品空：「这个生意账本还没有商品」+ 按钮「添加商品」。
- 图标使用线性风格，主色 30% 透明度，避免过重。

### 5.7 加载态

| 场景 | 方式 |
| --- | --- |
| 表格/列表加载 | `v-loading` 遮罩（EP），文案「加载中…」 |
| 卡片数字加载 | `el-skeleton`（3 张卡片骨架，数字位用 `el-skeleton-item variant="h3"`） |
| 图表加载 | ECharts `showLoading()` 内置 loading，文案「图表加载中」 |
| 保存/提交 | 按钮 `loading` 态，禁用重复提交 |
| 切换账本 | 内容区整体 `v-loading` + 200ms 过渡 |

### 5.8 来源平台标签 `<PlatformTag>`

- 小图标 + 平台名，`el-tag` `effect="plain"` `size="small"`，中性灰底。
- 微信→绿点、支付宝→蓝点、现金→灰点（点用色区分，文字统一中性，避免与收支红绿混淆）。

### 5.9 删除二次确认

- 统一用 `ElMessageBox.confirm`，标题「确认删除」，类型 `warning`。

- 金额为空或 0 → 保存按钮禁用，提示「请输入金额」。

- 保存成功 → `ElMessage.success`（带金额与方向，红绿色文字）。
- 保存按钮颜色随 flow：支出红、收入绿，强化方向感。

**生意账本增强（P1）**

- flow=收入 且为生意账本时，常用类目区下方追加「关联商品」入口：选商品 → 自动带出售价、可填数量 → 金额可由「售价×数量」自动算出（仍可手改）。便于后续利润核算。

## 8. 响应式断点策略（PC 优先，移动端浏览器可用）

### 8.1 断点定义（对齐 Element Plus）

| 断点 | 宽度 | 设备 | 布局策略 |
| --- | --- | --- | --- |
| `xl` | ≥1920px | 大屏 | 内容区最大宽 1440px 居中，两侧留白 |
| `lg` | ≥1200px | 桌面（主场景） | 完整左导航 + 多列卡片，三卡一行 |
| `md` | ≥992px | 小桌面/横屏平板 | 左导航默认折叠为图标，卡片两列 |
| `sm` | ≥768px | 竖屏平板 | 左导航转抽屉（汉堡触发），卡片两列 |
| `xs` | <768px | 手机浏览器 | 左导航抽屉，单列堆叠，表格转卡片列表 |

### 8.2 各断点适配规则

- **左导航**：`lg+` 常驻；`md` 折叠为图标条；`sm/xs` 收为顶栏汉堡 `☰` 触发的 `el-drawer`。
- **顶栏账本切换器**：始终保留（移动端是核心上下文）；搜索框在 `xs` 收为图标。
- **仪表盘卡片**：`lg` 三列（span8）→ `md` 两列（span12）→ `xs` 单列（span24，纵向堆叠）。
- **表格 → 卡片**：`xs` 下账目列表/商品列表把每行渲染为卡片（类目+金额为主，时间/平台次要），避免横向滚动。或对表格包 `overflow-x:auto` 作为退化方案。
- **快捷记账**：移动端默认显示数字键盘（触屏友好），抽屉变为底部上滑面板（`el-drawer direction="btt"`），全宽。这是移动端核心入口，需大按钮、≥44px 触控区。
- **筛选区**：`xs` 下筛选项纵向堆叠或收进「筛选」抽屉，避免挤压。
- **图表**：`xs` 下并排的两图改为上下堆叠，单图全宽，高度可降到 240px。
- **按钮触控区**：移动端所有可点元素最小 `44×44px`（含快捷类目按钮、数字键盘）。

### 8.3 实现建议

- 用 EP `el-col` 的 `:xs :sm :md :lg :xl` 响应式属性，避免手写媒体查询。
- 全局提供 `useBreakpoint()` composable（基于 `window.matchMedia` 或 VueUse `useBreakpoints`）驱动导航形态切换。
- 移动端检测后默认开启快捷记账数字键盘。

## 9. 可访问性（A11y）要点

### 9.1 对比度（WCAG 2.1 AA）

- 正文文本（`#1F2329` on `#FFFFFF`）对比度 ≈ 15:1，远超 AA。
- 收入绿 `#1FA971` on 白 ≈ 3.4:1 —— 作为大号金额（≥18px/600）满足 AA 大文本（3:1）；**作为小号文本或唯一信息载体时，必须叠加符号/图标，不能只靠颜色**。
- 支出红 `#E04C4C` on 白 ≈ 4.0:1，达标。
- 主色 `#3B6EF6` on 白 ≈ 4.0:1，按钮文字用白色（`#3B6EF6` 底 + 白字 ≈ 4.0:1，按钮文字≥14px 达标）。
- **不依赖颜色单通道**：收支除红绿外，必带 `+`/`−` 符号与「收入/支出」文字 Tag，色盲用户可辨。

### 9.2 键盘可达性

- 全功能键盘可操作：Tab 顺序符合视觉流（账本切换器→导航→主内容→操作）。
- 快捷记账提供完整快捷键（见 7.2），并在界面角落给「快捷键说明」入口（`?` 键唤出）。
- 聚焦指示：所有可聚焦元素聚焦时 2px 主色描边（`outline: 2px solid #3B6EF6; outline-offset: 2px`），禁止 `outline:none` 无替代。
- 弹窗/抽屉：打开时焦点移入、`Esc` 关闭、关闭后焦点归还触发元素（EP `el-dialog`/`el-drawer` 默认支持，保留即可）。

### 9.3 语义与读屏

- 金额组件加 `aria-label`，如「支出 128 元」「收入 256 元」，避免读屏读出 `−¥` 含糊。
- 表格列头用 `<th scope="col">`（EP `el-table` 默认语义可用）。
- 图标按钮（编辑/删除）须有 `aria-label` 与 `el-tooltip` 文字说明，不可纯图标。
- 表单错误：`el-form` 校验信息与字段关联（`aria-describedby`），错误时 Message + 字段红框 + 文字说明三重提示。
- 状态色提示（如负毛利标红）同时给文字/图标，不靠纯背景色。

### 9.4 其他

- 动效尊重 `prefers-reduced-motion`：开启时禁用非必要过渡（账本切换淡入、行高亮闪烁）。
- 字号支持浏览器缩放至 200% 不破版（用 rem/相对单位关键布局）。
- 颜色语义在文档与代码注释中固化，避免后续误用。
